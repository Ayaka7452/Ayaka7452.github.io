DayMate

一款轻量的 Android 倒数日应用，记录你的期待与坚持。
自己日常在用，顺手开源了。

下载 DayMate GitHub 开源

能做什么

小而全，把倒数日该有的都装进去了，没有多余的。

📅

倒数日

还有 N 天 / 已过 N 天，按天 / 月 / 年显示，支持对照日期与循环重复。

🏮

节日卡片

法定节假日倒计时，休 / 班状态、连休天数一卡看清。

🗂️

文件夹

用文件夹整理事件，支持批量管理。

🔒

Vault 私密空间

独立空间，密码 + 生物识别解锁，防截屏保护。

🌸

周期管家

私密的经期记录与预测。

🧩

桌面小组件

不打开应用也能看到最近的倒数。

☁️

数据备份

本地备份与 WebDAV 云同步，数据始终在你手里。

🎨

主题与语言

浅色 / 深色主题，多套配色，六种语言支持。

🔄

应用内更新

自动检查新版本并安装，保持最新。

界面一览

清爽留白，Material 3 风格。
